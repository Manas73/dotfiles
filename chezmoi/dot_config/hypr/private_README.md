# Hyprland Configuration

Lua config loaded by `hyprland.lua`. Quickshell is the bar, notifications,
and OSD.

## Directory Structure

```
~/.config/hypr/
├── hyprland.lua           # Main entry point (requires all modules)
├── conf/                  # Core configuration modules
│   ├── monitors.lua       # Monitor setup & workspace assignments
│   ├── environment.lua    # Environment variables
│   ├── programs.lua       # Program definitions (terminal, browser, …)
│   ├── autostart.lua      # Startup applications
│   ├── input.lua          # Input devices, keyboard, gestures
│   ├── appearance.lua     # Visual settings (general, decoration, animations)
│   └── layouts.lua        # Window layouts
├── keybinds/              # Keybinding modules
│   ├── base.lua           # Core keybindings (kill, float, lock, …)
│   ├── applications.lua   # App launchers
│   ├── window-mgmt.lua    # Focus, move, resize windows
│   ├── workspaces.lua     # Workspace switching & moving
│   └── submaps.lua        # Rofi menus, IDE selector, groups
├── rules/
│   ├── layer-rules.lua    # Layer rules (quickshell, rofi, copyq blur)
│   └── window-rules.lua   # Window rules (app workspaces, float, …)
└── colors/                # Theme colors (generated by matugen)
    ├── matugen.lua
    └── matugen.conf
```

## Reloading

```bash
hyprctl reload
```
